# steam-art-scraper

Скачивает арт Steam-приложений: капсулы, хедер, хиро, арт библиотеки, лого, фон страницы,
скриншоты — и самый новый трейлер (`trailer.mp4`, не выше 1080p и 60 fps). Остальные видео
пропускаются.

Трейлер в Steam хранится как DASH-поток (отдельно видео и аудио); они скачиваются по сегментам
и склеиваются без перекодирования через ffmpeg из пакета `imageio-ffmpeg` — ставить ffmpeg
отдельно не нужно. Трейлер весит десятки мегабайт и качается дольше всего остального арта, поэтому
его сегменты качаются параллельно (до 8 одновременно), а игры импортируются по 3 одновременно.

## Быстрый старт (Windows)

1. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/) — в PowerShell:
   `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`.
2. Откройте `_TO_IMPORT.txt` и впишите игры по одной на строку — app id или ссылку на страницу
   в Steam:

   ```text
   367520
   https://store.steampowered.com/app/1030300/Hollow_Knight_Silksong/
   ```

   Строки, начинающиеся с `#`, игнорируются.
3. Запустите `_RUN.bat` двойным кликом.
4. Арт появится в папке `output`.

Игра сначала скачивается в папку `… .partial` и переименовывается только после полной загрузки.
Если закрыть окно посреди импорта, недокачанная `.partial`-папка удалится при следующем запуске.

## Командная строка

```sh
uv run src/cli.py 367520 https://store.steampowered.com/app/1030300/ -o output
uv run src/cli.py --file _TO_IMPORT.txt
uv run src/cli.py 367520 --list   # только вывести URL
```

Каждое приложение сохраняется в `<out>/<ГГГГММДД ЧЧММСС> - <Название> (<обзоров>, <% положительных>)`,
например `20261029 223000 - Hollow_Knight (507705, 96%)`. Обзоры берутся из API магазина: отфильтрованные
как не относящиеся к игре не учитываются, доля положительных — в целых процентах.

После импорта в `<out>` пересобираются папки по типам арта (`_logo`, `_header`, `_library_hero`,
`_library_capsule`, `_hero_capsule`, `_small_capsule`, `_trailer` и т.д.) с жёсткими ссылками на файлы всех
игр: `_logo/<папка игры>.png`. Скриншоты не группируются. Жёсткая ссылка — тот же файл, что и в
папке игры: правка одного меняет другой. Нужна файловая система NTFS (на FAT32/exFAT группировка
не работает).

## Разработка

Нужен [uv](https://docs.astral.sh/uv/).

```sh
uv sync
uv run prek install
```

Хук запускает `ruff format`, `ruff check --fix`, `pyrefly check`, `pytest` и проверяет, что в
`_TO_IMPORT.txt` нет записей (только комментарии). Запустить вручную на всех файлах:

```sh
uv run prek run --all-files
```
